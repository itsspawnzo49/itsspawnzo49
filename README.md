### Hi, I'm itsspawnzo49! 👋

I build mobile apps with Flutter and React Native, mostly trying to make things that don't feel like they were assembled from the same template everyone else uses. Lately I've been obsessed with animations that respond to touch the way physical objects do, and with offline-first architectures that treat connectivity as a luxury rather than a foundation. Somewhere along the way I realized that the apps I remember aren't the ones with the most features, but the ones that felt like someone actually thought about how a thumb moves across glass.
